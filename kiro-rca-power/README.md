# rca-fleet Kiro power

A [Kiro power](https://kiro.dev/docs/powers/create/) that connects to the fleet's **AgentCore
task gateway** over HTTPS. Kiro signs in through the **Cognito hosted UI** (email and
password); no AWS CLI profile or local MCP server is required.

## Install

After `make deploy`, create a user in the Cognito console, render gateway settings into
`mcp.json`, then install:

```bash
make power
```

Or by hand:

```bash
python scripts/render_power_mcp.py --outputs ~/.rca/stack-outputs.json
kiro-cli powers install /absolute/path/to/kiro-rca-power
```

Kiro IDE: **Powers** → **Add Custom Power** → **Import power from a folder** → this directory.

## Sign in

When Kiro connects to `rca-fleet`, it opens the Cognito hosted UI. Use the email and password
an operator created in the `rca-tasks` user pool. On first login you set a permanent password.

## Tools

The gateway exposes four tools (names are prefixed with `rca-tasks___`):

- `rca-tasks___submit_task`
- `rca-tasks___get_task`
- `rca-tasks___list_tasks`
- `rca-tasks___cancel_task`

The dispatch skill in `skills/dispatch-task/` describes how to use them.

## Engineers with AWS IAM

The IAM-signed function URL and `scripts/rca_cli.py` / `make task` are unchanged for operators
who prefer SigV4.

## `mcp.json`

`mcp.json` is generated by `scripts/render_power_mcp.py` from CloudFormation outputs and is
gitignored. Re-run `make power` after each deploy that changes the task gateway.
